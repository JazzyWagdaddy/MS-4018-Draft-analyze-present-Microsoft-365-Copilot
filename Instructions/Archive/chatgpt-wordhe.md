# Microsoft Copilot in Word: A 45-Minute Hands-On Lab

GITHUB-HOSTED WORKSHOP · UNIVERSITY FACULTY & STAFF · BEGINNER–INTERMEDIATE

**Lab title:** *From First Draft to Final Document: Five Practical Microsoft Copilot Workflows*

This lab teaches university faculty and staff how to use **Microsoft 365 Copilot in Word** to draft, summarize, rewrite, transform, and review professional documents.

The workshop is designed for participants to follow independently through a GitHub repository while an instructor demonstrates Copilot capabilities and facilitates hands-on exercises.

## Learning objectives

By the end of this lab, participants will be able to:

1. **Draft a new Word document** from a short brief using Copilot.
2. **Summarize a longer document** for a specific university audience.
3. **Rewrite and improve text** for clarity, tone, accessibility, and usefulness.
4. **Transform existing content** into a different document format or structure.
5. **Review and refine a document** against defined requirements using Copilot.

## Prerequisites

Participants should have Microsoft Word (desktop or web), an institutional Microsoft 365 account with appropriate Copilot capabilities enabled, and access to the GitHub lab repository.

Copilot functionality varies by license, Word version, and institutional configuration. The lab should be tested against the university's deployment before delivery.

## Lab scenario

Participants work with fictional materials for a university-wide **Faculty and Staff Digital Skills Initiative**.

The five exercises build on a realistic document workflow: preparing an announcement, summarizing planning information, improving communications, transforming meeting notes, and checking the final document against university requirements.

## Hands-on exercises

**Exercise 1 — Draft a new document with Copilot**

7 MINUTES · WORD + COPILOT

Open a blank Word document and use Copilot to draft a university announcement from the provided event brief.

**Starter prompt:**

> Draft a 300-word announcement for university faculty and staff using the event brief below. Include the initiative's purpose, benefits, participation details, and a call to action. Use a welcoming, professional tone. Do not invent missing details.

**Challenge:** Refine the draft by specifying a different audience or tone. Review the result before keeping it in Word.

---

**Exercise 2 — Summarize a longer document**

7 MINUTES · COPILOT CHAT IN WORD

Open the provided committee report in Word, then ask Copilot to summarize the document for department chairs.

**Starter prompt:**

> Summarize this document for university department chairs in no more than 200 words. Focus on key decisions, resource implications, implementation risks, and required actions. Distinguish recommendations from approved decisions.

**Challenge:** Ask Copilot to summarize the same document for administrative staff. Compare what it emphasizes for each audience.

---

**Exercise 3 — Rewrite and improve text**

7 MINUTES · SELECT TEXT + COPILOT REWRITE

Open the draft announcement, select a paragraph, and use the available Copilot rewrite or editing action.

**Starter prompt:**

> Rewrite this text in clear, accessible language appropriate for faculty and staff. Use active voice, shorter sentences, and a friendly but professional tone. Preserve all verified facts, dates, and requirements.

**Challenge:** Compare the original and rewritten versions, then decide which edits to retain.

---

**Exercise 4 — Transform content into another document type**

7 MINUTES · COPILOT CHAT + WORD FORMATTING

Open the provided meeting notes and use Copilot to transform them into a structured project status report.

**Starter prompt:**

> Transform these meeting notes into a one-page project status report. Include accomplishments, upcoming milestones, action items, responsible owners, risks, and unresolved questions. Do not invent decisions, deadlines, or owners.

**Challenge:** Convert the same information into a concise email update for a department administrator. Use Word's formatting tools to finalize the document.

---

**Exercise 5 — Review and refine a document**

8 MINUTES · COPILOT CHAT + HUMAN REVIEW

Return to the announcement created in Exercise 1. Use Copilot to compare it against a supplied university communications checklist.

**Starter prompt:**

> Review this announcement against the requirements below. Identify which requirements are met, partially met, or missing. Provide a table with evidence and recommended changes. Then suggest a revised version that addresses the issues without introducing unsupported facts.

**Challenge:** Apply selected revisions and ask Copilot to check the updated document again.

## Copilot-specific instructional considerations

The lab should emphasize how Copilot operates **inside Word**, rather than treating it as a general-purpose chatbot. Participants should practice selecting text, working with the Copilot pane, reviewing generated content, and incorporating changes into their documents.

For the university setting, participants should also understand that Copilot output requires verification, institutional data-handling policies still apply, and human authors remain responsible for final communications.

## Facilitator guidance

Each exercise follows a consistent sequence: demonstrate the relevant Copilot interaction, let participants complete the task, introduce a prompt refinement, and briefly discuss the output.

The closing reflection asks participants to identify one document workflow they could improve using Copilot and one human review step they would always retain.

**Recommended implementation:** Publish the exercises as Markdown pages in GitHub and provide actual `.docx` sample files for download. This allows participants to follow the instructions in their browsers while working directly in Microsoft Word.

The result is a cohesive, 45-minute lab focused specifically on **Microsoft 365 Copilot in Word**, with realistic faculty and staff use cases rather than generic AI prompting exercises.
